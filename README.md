
# 🌍 Tradutor Multilíngue com Kivy

Um tradutor simples e estiloso criado com Python, usando **Kivy** para a interface gráfica e a biblioteca `translate` para tradução de textos. Suporta 4 idiomas: **Português**, **Inglês**, **Espanhol** e **Francês**.

## ✨ Funcionalidades

- Interface leve e responsiva com Kivy
- Tradução entre os idiomas suportados
- Interface intuitiva para digitar e obter o resultado da tradução

## 🧠 Tecnologias usadas

- [Python 3.x](https://www.python.org/)
- [Kivy](https://kivy.org/)
- [translate](https://pypi.org/project/translate/).

## 📦 Instalação

1. Clone este repositório:

```bash
git clone https://github.com/lavicardosoo/python-translator.git
cd python-translator
```

2. Crie e ative um ambiente virtual (opcional, mas recomendado):

```bash
python3 -m venv venv
source venv/bin/activate  # Linux/macOS
venv\Scripts\activate     # Windows
```

3. Instale as dependências:

```bash
pip install kivy translate
```

> Obs: substitua `translate` por `translator` se for o caso.

## 🚀 Como executar

```bash
python python-translator.py
```

A interface será aberta com campos para digitação, seleção de idioma e exibição da tradução.
